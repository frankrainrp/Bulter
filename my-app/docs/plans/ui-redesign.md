# Interface implementation reference

The implemented workspace uses a top-level tab bar, contextual left rail and main canvas. Tasks, calendar, notes and chat share typed records, global search, notifications and linked navigation. Preferences and learning tools use existing drawers or dialogs.

Preserve the established spacing, tokens, character artwork and responsive layout when changing data behavior. Navigation should retain selection and draft state, expose keyboard focus and provide empty/error states. Use the current components as the design reference; previous comparison pages are retained in Git history.
